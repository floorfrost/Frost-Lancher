## ❄️ About Frost Launcher

**Frost Launcher** is a modern, fast, and feature-rich Minecraft launcher redesigned and maintained by **Floor Frost Creations**. It provides seamless Minecraft version management, high-speed concurrent downloads, and built-in support for modloaders and modpacks.

Visit our **[Official Site (floorfrost.xo.je)](https://floorfrost.xo.je)** for more information and updates!

---

## ✨ Features

- 📥 **Download & Auto-Complete**: Support for downloading `Minecraft`, `Forge`, `Fabric`, `NeoForge`, `Quilt`, and `OptiFine`.
- ⚡️ **High-Speed Downloads**: Concurrent multi-part downloading with mirror acceleration.
- 💻 **Cross Platform**: Built on modern Electron architecture, supporting Windows 10/11, macOS, and Linux.
- 📚 **Multi-Instance Management**: Create and isolate multiple game profiles, modpacks, and launch settings.
- 🗂 **Smart Resource Handling**: Hard/symbolic link management to minimize disk space.
- 🔥 **Modrinth & CurseForge Integration**: Browse, install, and manage mods directly within the launcher.
- 🔒 **Multiple Account Systems**: Support for Microsoft authentication, Mojang, and custom auth servers.
- 🔗 **P2P Multiplayer**: Play over LAN with friends anywhere via built-in peer-to-peer networking.
